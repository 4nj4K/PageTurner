# PageTurner

> A modern, full-stack book tracking web application built to manage reading lists, track reading status, and record personal notes with a sleek, responsive UI.

---

## Features

- **Book Management:** Add, view, and delete books with tracking for titles, authors, genres, status, and ratings.
- **Personal Notes:** Attach custom thoughts, reviews, or notes to any book entry.
- **Interactive Dashboard:** Real-time statistics tracking total books, finished reads, currently reading items, and average ratings.
- **Dynamic Filtering & Sorting:** Search and filter books effortlessly by title/author or status.
- **Modern UI/UX:** Designed with a vibrant light-mode gradient, glassmorphism cards and smooth animations.

---

## Tech Stack 

### Backend
- **C# & .NET 9 Web API**
- **Entity Framework Core (EF Core)**
- **SQLite** (Local relational database)

### Frontend
- **HTML5 & CSS3** (Custom styling with CSS variables, Flexbox & Grid)
- **Vanilla JavaScript** (Async/Await for seamless API communication)
